FIR

Forensic Intelligence Repository — the single source of truth

Stores the analyzed FCR (Forensic Correlation Record) objects from preprocessing plus every Layer 4 finding, each with its confidence score and evidence reference. Nothing enters the AI layer that isn't traceable back to a record here.

↓FIR facts
SG

Evidence Sanitization Gateway

shared trust boundary — FIR → AI layer

Cleans evidence text before any agent reads it — wraps free text in strict delimiters and strips or flags injection attempts (e.g. “ignore previous instructions”) before it ever reaches an LLM prompt. One shared implementation used by every agent below, not duplicated per-agent. Agent 7's Call 2 (Independent Verification) is the backstop for anything that slips past this gateway.

↓sanitized text

↯ Investigation State Manager — cross-cutting, spans every stage above

  • Per-case state machine — pending / running / complete / failed, tracked per stage, not just per case
  • Progress — per-artifact & per-agent granularity (e.g. "6/8 formats parsed", "Agent 4 running")
  • Retry & backoff — automatic retry on transient failure, capped before escalating to manual intervention
  • Crash recovery / checkpointing — resumes a case from its last-completed stage instead of restarting from Evidence Upload
  • Failure classification — infra crash vs. deterministic parser error vs. AI agent failure (timeout, malformed output, failed Call 2 verification), each routed differently
  • Writes state transitions into the Infrastructure Layer's audit log — operational status, distinct from evidentiary chain-of-custody

↻ Continuous Evaluation & Drift Monitoring

  • Scheduled test runs against known cases
  • Hallucination rate tracked over time
  • Attribution precision — do citations actually support claims
  • Injection red-team suite — attacks the Sanitization Gateway
