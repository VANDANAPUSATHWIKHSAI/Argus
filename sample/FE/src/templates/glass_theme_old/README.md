# Glass Theme Old Snapshot (glass_theme_old)

Saved on: **October 23, 2026**

This directory stores the complete snapshot of the ARGUS Glass Dashboard and Glass System templates under the identifier **`glass_theme_old`**.

## Contents

1. **`GlassDashboardTemplate.jsx`**:
   - The primary interactive Frosted Glass dashboard.
   - Vertically centered floating navigation sidebar card (`top: calc(50% - 60px); transform: translateY(-50%)`).
   - Dedicated separate bottom-left session anchor card for user profile and logout (`bottom: 20px; left: 20px`).
   - Full-width floating topbar island capsule centered at the top of the viewport (`top: 20px; left: 50%; transform: translateX(-50%); width: calc(100vw - 40px)`).

2. **`GlassDashboardTemplate.css`**:
   - Complete glass design tokens.
   - Refined **greyish-black** dark mode canvas (`#181a20`) with charcoal glass surfaces and crisp specular rims.
   - Neutral light frosted glass mode (`#eef2f7`).
   - Clean micro-animations, glass border masks, and glow effects.

3. **`glass/`**:
   - `GlassSystem.css`: Core glass UI tokens and utilities.
   - `ForensicGlobeCanvas.jsx`: 3D interactive wireframe globe canvas.
   - `GlassTemplateGallery.jsx` & `GlassTemplateGallery.css`: Full gallery previewer.
   - `GlassTemplateSwitcherBar.jsx` & `GlassTemplateSwitcherBar.css`: Floating preview pill.
   - Five specialized glass sub-templates:
     - `Template1Architectural.jsx` / `.css` (Architectural Glass)
     - `Template2Liquid.jsx` / `.css` (Liquid Frosted Glass)
     - `Template3Obsidian.jsx` / `.css` (Obsidian Charcoal Glass)
     - `Template4Aurora.jsx` / `.css` (Aurora Prismatic Glass)
     - `Template5Prismatic.jsx` / `.css` (Prismatic Crystal Glass)
